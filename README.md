# 📝 Advanced To-Do App

An advanced and responsive To-Do web application built using HTML, CSS, and JavaScript. This app allows users to efficiently manage daily tasks with persistent data storage.

## 🚀 Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks (All / Completed / Pending)
- Due date support
- Data persistence using Local Storage

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
